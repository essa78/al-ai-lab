Summer Research Awards

SemesterStudentProjectDescription
Summer 2026Wilson VongSimClassAI: AI-Powered Classroom Simulation for Teacher PreparationThis project develops an AI Agent-Based Virtual Classroom Simulator that enables undergraduate and graduate education students to interact with realistic virtual K-12 learners exhibiting diverse academic abilities, personalities, learning styles, emotional states, and classroom behaviors.
Summer 2026Brynne SmithAI-Based Hand Gesture Recognition System for Real-Time Drone Control Using Wearable Inertial SensorsThis AI-driven gesture recognition system processes data from a single wearable sensor to enable real-time, hands-free drone flight.
  • Wearable Inertial Sensing: Uses a wrist-mounted MetaMotionRL device to track physical movement, bypassing the need for complex external camera setups.
  • Tri-Axis Data Collection: Captures simultaneous accelerometer, gyroscope, and orientation measurements to pinpoint exact wrist and hand movements.
  • Predefined Command Translation: Converts distinct hand gestures into live flight commands, including takeoff, landing, directional movement, and rotation.
  • Comparative Machine Learning: Benchmarks Random Forest, Support Vector Machine (SVM), K-Nearest Neighbors (KNN), and XGBoost.
  • Versatile Framework Application: Establishes a foundation for robotics, assistive technologies, and real-time smart controls.
Summer 2025Wilson VongHoloPose: Real-time 3D human pose estimation on Microsoft HoloLens for augmented reality interactionThis real-time augmented reality system delivers local, touch-free skeletal tracking directly on a headset to transform physical rehabilitation.
  • Standalone Device Processing: Performs 3D skeletal pose estimation directly on Microsoft HoloLens.
  • Intelligent HoloPose Method: Uses the headset's built-in camera and sensor suite to map body movements in real time.
  • Intuitive Virtual Interaction: Enables natural, hands-free interaction with virtual objects.
  • Enhanced Patient Mobility: Provides a portable setup for flexible room-to-room use.
  • Publications: The foundational framework was published and presented in SPIE conference proceedings.
Summer 2025Frank GalloFrom Brainwaves to Motion: A Hybrid BCI Approach for Hands-Free Assistive TechnologyThis hybrid brain-computer interface combines neural signals and motion tracking to deliver reliable, responsive device control.
  • Dual-Data Integration: Pairs EEG brainwaves with inertial sensor data.
  • Streamlined 5-Channel Tracking: Uses the EMOTIV Insight headset.
  • Seven-State Recognition: Decodes neutral, focused, eye blink, and four motion directions.
  • Advanced Signal Preprocessing: Uses bandpass filtering and Fast Fourier Transform analysis.
  • Smart Classification Switching: Uses a Random Forest Classifier to determine when to shift between mental and motion states.
Summer 2024Sahana AbbennagariContactless System for Real-Time Heart and Respiration Rate TrackingThis contactless monitoring system transforms standard webcam video into a live health tracker.
  • Touch-Free Metrics: Tracks heart rate and respiration rate wirelessly.
  • Real-Time Analysis: Provides immediate, continuous feedback through a browser or app.
  • Proven Technology: Uses the green spectrum in RGB video frames to isolate facial blood-flow pulsations.
  • Smart Region Isolation: Locks onto skin regions to reduce movement-related disruption.
